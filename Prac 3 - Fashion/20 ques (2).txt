🔴 Practical 3: Fashion MNIST (CNN)
🎤 20 Viva Questions + Answers

What is the aim of this practical?
👉 The aim is to classify fashion images into different categories using CNN.

What type of problem is this?
👉 This is a multi-class classification problem.

What is the Fashion MNIST dataset?
👉 It is a dataset of grayscale images of clothing items.

Why do we normalize image data?
👉 Normalization scales pixel values to improve model performance.

What is CNN?
👉 CNN is a neural network designed specifically for image processing tasks.

What does Conv2D layer do?
👉 It extracts important features like edges and patterns from images.

What is a filter in CNN?
👉 A filter is a small matrix used to detect features in an image.

Why is ReLU used?
👉 ReLU helps in faster training and introduces non-linearity.

What is MaxPooling?
👉 It reduces image size and helps in reducing computation.

Why do we use Flatten layer?
👉 It converts 2D feature maps into a 1D vector for Dense layers.

Why is Dense layer used at the end?
👉 It performs final classification based on extracted features.

Why softmax activation?
👉 Softmax converts output into probabilities for multiple classes.

What is sparse categorical crossentropy?
👉 It is a loss function used for multi-class classification.

What is accuracy in this model?
👉 It represents how many predictions are correct.

What does model.fit() do?
👉 It trains the model on image data.

What does model.evaluate() do?
👉 It measures model performance on test data.

What is overfitting in CNN?
👉 When the model memorizes training images but fails on new images.

Why CNN over DNN for images?
👉 CNN captures spatial features better than DNN.

What is feature map?
👉 It is the output of convolution layer showing detected features.

How can you improve CNN performance?
👉 By adding more layers, dropout, or data augmentation.
