WHAT THIS PRACTICAL DOES
--------------------------
We build a Deep Neural Network (DNN) that reads a movie review
and predicts whether it is POSITIVE or NEGATIVE.

This is called Binary Classification — only 2 possible outputs:
  1 = Positive review
  0 = Negative review

Dataset: IMDB — 50,000 movie reviews
  25,000 for training
  25,000 for testing


================================================================
CELL BY CELL CODE EXPLANATION
================================================================

----------------------------------------------------------------
CELL 1 — Import Libraries
----------------------------------------------------------------

import numpy as np
  For array operations and creating zero matrices.

import tensorflow as tf
  Google's deep learning framework.

from tensorflow import keras
  High-level API to build and train neural networks easily.

from tensorflow.keras import layers
  Provides Dense layer (fully connected layer).

import matplotlib.pyplot as plt
  For plotting accuracy and loss graphs.

print("TensorFlow version:", tf.__version__)
  Just prints which version of TensorFlow is installed.
  Useful to confirm TF is working correctly.


----------------------------------------------------------------
CELL 2 — Load the IMDB Dataset
----------------------------------------------------------------

NUM_WORDS = 10000
  We only keep the 10,000 most frequently used words.
  Less common / rare words are ignored.
  Reduces vocabulary size and makes training faster.

(x_train, y_train), (x_test, y_test) = keras.datasets.imdb.load_data(num_words=NUM_WORDS)
  Downloads and loads the IMDB dataset automatically from Keras.
  No separate CSV file needed.

  x_train = 25,000 training reviews (each as list of word numbers)
  y_train = 25,000 labels (0 or 1) for training
  x_test  = 25,000 test reviews
  y_test  = 25,000 labels for testing

  Example: x_train[0] = [1, 14, 22, 16, 43, 530, ...]
  Each number = a word's rank in frequency.
  Word 1 = most common word, Word 9999 = 9999th most common.

  y_train[0] = 1 means first training review is POSITIVE.

print statements:
  Shows 25000 training and 25000 test samples.
  Shows first review's label and first 10 word indices.


----------------------------------------------------------------
CELL 3 — Preprocess Data (Vectorize)
----------------------------------------------------------------

WHY do we need this?
  Reviews have different lengths — some 50 words, some 500 words.
  Neural networks need ALL inputs to be the SAME SIZE.
  We convert every review to a fixed 10,000-sized vector.

def vectorize_sequences(sequences, dimension=NUM_WORDS):
  Function to convert list of word indices into a vector.

results = np.zeros((len(sequences), dimension))
  Creates a matrix of all zeros.
  Shape: (25000, 10000) — 25000 reviews, each 10000 positions.

results[i, sequence] = 1.0
  For each review, set the positions of words that appear to 1.
  This is called Multi-Hot Encoding (also called Bag of Words).

  Example: Review has words [5, 22, 198]
  Position 5   = 1
  Position 22  = 1
  Position 198 = 1
  All other 9997 positions = 0

x_train_vec = vectorize_sequences(x_train)
x_test_vec  = vectorize_sequences(x_test)
  Apply vectorization to both train and test data.
  Shape after: (25000, 10000) for both.

y_train = y_train.astype('float32')
y_test  = y_test.astype('float32')
  Convert labels from integers to float32.
  Required by TensorFlow for loss calculation.

print shapes:
  Confirms x_train_vec is (25000, 10000).
  Each review is now a vector of 10000 numbers (0s and 1s).


----------------------------------------------------------------
CELL 4 — Build the Neural Network
----------------------------------------------------------------

model = keras.Sequential([...])
  Sequential = layers stacked one after another in order.

layers.Dense(16, activation='relu', input_shape=(NUM_WORDS,))
  HIDDEN LAYER 1:
  16 neurons. Takes 10,000 inputs (one per word).
  ReLU activation: output = max(0, x) — removes negatives.
  input_shape=(10000,) tells model the size of each input.

layers.Dense(16, activation='relu')
  HIDDEN LAYER 2:
  16 neurons. Takes 16 inputs from previous layer.
  ReLU again. Learns more complex patterns.

layers.Dense(1, activation='sigmoid')
  OUTPUT LAYER:
  1 neuron — gives ONE probability value.
  Sigmoid: converts any value to range 0.0 to 1.0.
  Output > 0.5 = Positive review.
  Output < 0.5 = Negative review.

model.summary()
  Prints the architecture:
    Layer 1: 16 neurons × (10000 inputs + 1 bias) = 160,016 params
    Layer 2: 16 neurons × (16 inputs + 1 bias)    = 272 params
    Output:   1 neuron  × (16 inputs + 1 bias)    = 17 params
  Total trainable parameters shown.


----------------------------------------------------------------
CELL 5 — Compile the Model
----------------------------------------------------------------

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

optimizer='adam'
  Adam = smart learning rate adjustment algorithm.
  Automatically tunes how fast the model learns.
  Faster and more reliable than basic Stochastic Gradient Descent.

loss='binary_crossentropy'
  Loss function for BINARY classification (2 classes: 0 or 1).
  Measures how wrong the prediction is.
  Formula: loss = -(y*log(p) + (1-y)*log(1-p))
  Lower loss = better predictions.

metrics=['accuracy']
  Track accuracy during training.
  Accuracy = correct predictions / total predictions.


----------------------------------------------------------------
CELL 6 — Train the Model
----------------------------------------------------------------

history = model.fit(x_train_vec, y_train, epochs=10, batch_size=512, validation_split=0.2, verbose=1)

x_train_vec, y_train
  Training data and labels.

epochs=10
  Go through all training data 10 complete times.
  Each round = 1 epoch. More epochs = more learning.

batch_size=512
  Update model weights after every 512 reviews.
  25000 / 512 ≈ 49 updates per epoch.

validation_split=0.2
  Use 20% of training data (5000 reviews) for validation.
  Model does NOT learn from these — only checks performance.
  Used to detect overfitting early.

verbose=1
  Shows progress bar for each epoch during training.
  Shows loss and accuracy values per epoch.

history
  Stores training and validation accuracy/loss for each epoch.
  Used later for plotting graphs.


----------------------------------------------------------------
CELL 7 — Plot Training Results
----------------------------------------------------------------

plt.subplot(1, 2, 1) — Accuracy plot:
  X-axis = Epoch number (1 to 10)
  Y-axis = Accuracy (0 to 1)
  Two lines: Train Accuracy and Validation Accuracy
  Both should go UP over epochs.

plt.subplot(1, 2, 2) — Loss plot:
  X-axis = Epoch number
  Y-axis = Loss value
  Two lines: Train Loss and Validation Loss
  Both should go DOWN over epochs.

What good graphs look like:
  Train accuracy ↑ and Val accuracy ↑ together = Good
  If Val accuracy drops while Train keeps rising = Overfitting


----------------------------------------------------------------
CELL 8 — Evaluate on Test Data
----------------------------------------------------------------

test_loss, test_accuracy = model.evaluate(x_test_vec, y_test, verbose=0)

  Returns final loss and accuracy on UNSEEN data.

print(f"Test Accuracy: {test_accuracy*100:.2f}%")
  Prints accuracy as percentage.
  Good model achieves around 87-88% accuracy.

================================================================
TEACHER QUESTIONS & ANSWERS
================================================================

Q. What is binary classification?
A. Classifying input into exactly 2 classes.
   Here: Positive (1) or Negative (0) review.

Q. What is the IMDB dataset?
A. 50,000 movie reviews — 25,000 train, 25,000 test.
   Each review is labeled 1 (positive) or 0 (negative).
   Built into Keras — no download needed.

Q. What is Multi-Hot Encoding / Vectorization?
A. Converts a review (list of word indices) into a 10,000
   size vector of 0s and 1s. Position i = 1 if word i appears
   in the review, else 0. Makes all reviews same fixed size.

Q. Why use Multi-Hot instead of Embedding?
A. Multi-hot is simpler — each word is just present/absent.
   Embedding is better for capturing word meaning but complex.
   Multi-hot works well for basic sentiment classification.

Q. What does num_words=10000 mean?
A. Only keep the 10,000 most common words.
   Rare words ignored. Reduces input size and training time.

Q. What is ReLU activation?
A. f(x) = max(0, x). Removes negatives, keeps positives.
   Used in hidden layers. Fast and avoids vanishing gradient.

Q. What is Sigmoid activation?
A. f(x) = 1 / (1 + e^-x). Outputs value between 0 and 1.
   Used in output layer for binary classification.
   Output > 0.5 = Positive, < 0.5 = Negative.

Q. Why binary_crossentropy loss?
A. It is the correct loss for binary (2-class) problems.
   Measures difference between predicted probability and
   actual label (0 or 1). Lower = better.

Q. What is validation_split=0.2?
A. 20% of training data kept aside during training.
   Model does NOT learn from it — used only to monitor
   if model is overfitting.

Q. What is overfitting?
A. Model memorizes training data but fails on new data.
   Sign: train accuracy high, val accuracy drops.
   Prevention: use validation split, reduce epochs.

Q. What is the model architecture?
A. Input: 10,000 (one per word)
   Hidden Layer 1: Dense(16, ReLU)
   Hidden Layer 2: Dense(16, ReLU)
   Output Layer:   Dense(1, Sigmoid)
   Loss: binary_crossentropy, Optimizer: Adam

Q. What accuracy does this model achieve?
A. Around 87-88% on the test set.
   Meaning ~87 out of 100 reviews are correctly classified.
