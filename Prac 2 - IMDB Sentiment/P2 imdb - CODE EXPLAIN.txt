Binary Classification — only 2 output classes.
Dataset: 50,000 reviews built into Keras. Already converted to numbers (word indices).
25,000 for training, 25,000 for testing.

================================================================
CELL 6 — Pad Sequences (Make All Reviews Same Length)
================================================================
Code: X_train = pad_sequences(X_train, maxlen=200, padding='post', truncating='post')
      X_test  = pad_sequences(X_test,  maxlen=200, padding='post', truncating='post')

- Neural networks need FIXED input size, but reviews have different lengths
- pad_sequences() fixes this:
    maxlen=200 → every review becomes exactly 200 words
    padding='post' → SHORT reviews: add zeros at the END
    truncating='post' → LONG reviews: remove words from the END
- After padding:
    X_train shape: (25000, 200) → 25,000 reviews, 200 words each
    X_test shape:  (25000, 200) → same

================================================================
CELL 7 — Build the Neural Network
================================================================
Code: model = keras.Sequential([
          Embedding(10000, 16, input_length=200),
          GlobalAveragePooling1D(),
          Dense(64, activation='relu'),
          Dropout(0.5),
          Dense(32, activation='relu'),
          Dropout(0.3),
          Dense(1, activation='sigmoid')
      ])
      model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

Layer by layer:

- Embedding(10000, 16, input_length=200):
    input_dim=10000 → vocabulary size (10,000 words)
    output_dim=16 → each word gets a 16-number vector (rich representation)
    input_length=200 → each review is 200 words
    Converts each word-index into a 16-dimensional dense vector
    The network LEARNS which words are similar during training

- GlobalAveragePooling1D():
    Takes the AVERAGE of all 200 word vectors in a review
    Converts shape (200, 16) → (16,) — one vector per review
    Summarizes the whole review into a single 16-number vector

- Dense(64, activation='relu'):
    Hidden layer 1, 64 neurons
    ReLU: f(x)=max(0,x) → learns non-linear patterns in review meaning

- Dropout(0.5):
    Randomly turns OFF 50% of neurons during each training batch
    Prevents overfitting — forces other neurons to learn
    NOT applied during testing/prediction

- Dense(32, activation='relu'):
    Hidden layer 2, 32 neurons, ReLU

- Dropout(0.3):
    Turns OFF 30% of neurons randomly during training

- Dense(1, activation='sigmoid'):
    Output layer — 1 neuron
    Sigmoid: output is between 0 and 1 (a probability)
    output > 0.5 → Positive, output < 0.5 → Negative

- model.compile():
    optimizer='adam' → adaptive gradient descent
    loss='binary_crossentropy' → loss function for binary classification
    metrics=['accuracy'] → track accuracy during training

- model.summary() → prints all layers, shapes, and parameter count

================================================================
CELL 8 — Train the Model
================================================================
Code: history = model.fit(X_train, y_train, epochs=10, batch_size=128, validation_split=0.2)

- model.fit() → starts training
- epochs=10 → model sees all training data 10 times
  (fewer than Boston because text models overfit faster)
- batch_size=128 → 128 reviews per batch before updating weights
  (larger batch → faster training for big text data)
- validation_split=0.2 → 20% of training (5,000 reviews) held for validation
- history → stores accuracy and loss per epoch for plotting

================================================================

================================================================

    test_acc → accuracy (e.g. 0.87 = 87% reviews correctly classified)
- verbose=0 → suppresses output during evaluation (no printing per batch)

================================================================
QUICK Q&A FOR TEACHER
================================================================

Q: Why use num_words=10000?
A: Limits vocabulary to top 10,000 words. Rare words don't help and waste computation.

Q: Why use pad_sequences?
A: Neural networks need fixed input size. Reviews have different lengths. Padding makes all reviews exactly 200 words.

Q: What is an Embedding layer?
A: Converts each word integer to a 16-number dense vector. The model learns which words are similar. Better than one-hot encoding.

Q: Why Sigmoid in output?
A: Gives probability between 0 and 1. Output > 0.5 = Positive, < 0.5 = Negative.

Q: What is Binary Cross-Entropy?
A: Loss function for 2-class problems. Measures how far predicted probability is from actual label (0 or 1).

Q: What is Dropout?
A: Randomly turns off neurons during training to prevent overfitting. Dropout(0.5) = 50% neurons disabled per batch.

Q: What is GlobalAveragePooling1D?
A: Averages all 200 word vectors into one single vector. Summarizes the whole review.
